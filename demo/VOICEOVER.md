# Demo voiceover

The sample video is **silent**. Add your own voice in Clipchamp or record live with **Win + G** and `npm run start:demo`.

Demo companies in the video:

| TPA | What it shows |
| --- | --- |
| **111111** | MDM has no account — message for MDM to create it. |
| **659592** | Account exists, **no TID** — both Account TID options (MDM patch vs Team Cotton). |
| **611521** | Full path — TID set, People check, Subscription. |

## Script

1. **111111** — “If MDM does not know this company yet, Check in MDM stops on step one. Contact the MDM team with the request below.”

2. **659592** — “When the account exists but has no TID, step two opens. If you already have the TTC account id, prepare the MDM message. If not, prepare the Cotton DEVSERVICE message.”

3. **611521** — “When the TID is already there, check People, then Subscription. You see Enable DTD subscription until LEM credentials are entered. For 611521 the subscription is already active, so Enable disappears and the Yard Documents link appears.”
